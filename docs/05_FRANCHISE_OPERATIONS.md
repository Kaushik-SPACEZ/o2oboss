## 💰 Franchise Investment

| Component | Description |
|-----------|-------------|
| Franchise Fee | One-time payment for rights |
| Setup Cost | Outlet construction, equipment |
| Initial Inventory | Starting stock |
| Working Capital | Operational buffer |
| **Total Investment** | Varies by franchise type |

### Example: Coffee Kiosk
- Franchise Fee: ₹2-5 Lakhs
- Setup: ₹3-5 Lakhs
- Inventory: ₹50K-1L
- Working Capital: ₹1-2L
- **Total: ₹7-13 Lakhs** (indicative)

## 📊 Revenue & Royalty Model

```
┌─────────────────────────────────────────────────────────────┐
│              FRANCHISE EARNINGS                             │
└─────────────────────────────────────────────────────────────┘

GROSS REVENUE (Monthly Sales)
        ↓
    - Cost of Goods Sold
    - Operating Expenses
    - Staff Salaries
    - Rent & Utilities
        ↓
    = OPERATING PROFIT
        ↓
    - Royalty to O2O Boss (5-10%)
    - Marketing Fund (2-3%)
        ↓
    = NET PROFIT (Franchisee keeps)
```

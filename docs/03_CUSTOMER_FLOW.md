## 📱 What Customer Can Do in App

### 1. **Home Dashboard**
- View personalized recommendations
- See nearby vendors
- Quick access to categories
- Current offers & deals

### 2. **Browse & Search**
- Search products/services
- Filter by category, price, location
- View vendor ratings
- Check QPS RIGHTS™ certification

### 3. **Order Products**
- Add to cart
- Apply coupons
- Choose delivery address
- Select payment method
- Track order status

### 4. **Book Services**
- View available slots
- Select service provider
- Book appointment
- Get confirmation
- Receive service

### 5. **Manage Profile**
- Update personal details
- Manage addresses
- View order history
- Track spending
- Saved favorites

### 6. **Support**
- Contact back office
- Raise complaints
- Request refunds
- Get help
